# WordCards
這是英文單字學習系統，提供單字瀏覽、發音播放、自動播放及單字編輯等功能，幫助使用者透過單字卡方式學習英文單字。
系統會從單字檔載入資料，並利用Windows Media Player元件播放單字發音。

主要功能
1. 載入單字資料

系統啟動時會讀取：

WordCards.txt

並將單字資料載入至單字清單。

2. 顯示單字資訊

選取單字後可顯示：

單字（Word）
音標（Phonogram）
中文解釋（Explain）
3. 播放單字發音

點擊單字後可播放對應的 mp3 音檔。

4. 自動播放模式

按下 Play 按鈕後：

自動播放目前單字
依照 Timer 設定時間切換至下一個單字
播放下一個單字發音

再次按下 Stop 可停止播放。

5. 鍵盤快捷鍵

Enter	播放下一個單字

Space	重播目前單字

6. 編輯單字

雙擊單字可開啟編輯視窗。

可修改：

單字
音標
音檔路徑
中文解釋

儲存後會更新單字資料並寫回 WordCards.txt。
